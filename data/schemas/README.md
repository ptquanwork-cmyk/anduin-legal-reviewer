# Output contracts

[review-result.schema.json](review-result.schema.json) is the proposed v1 contract for review results. It describes exact source evidence, category, explanation, confirmation question, and review status.

This is a local JSON Schema draft, not a tested API integration. The selected API/model must support its shape before the application uses it. Successful schema validation does not prove evidence correctness; quote/location checks and human review remain necessary.
