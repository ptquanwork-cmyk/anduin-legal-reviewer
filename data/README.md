# Public data

- `demo-contracts/`: synthetic fund subscription documents (Word, PDF, scrambled scan, long booklet, Vietnamese, fillable form) for trying the whole workflow; see its README for the planted problems.
- `synthetic/`: fictional text samples used by tests and evaluations.
- `schemas/`: versioned output contracts.

Evaluation cases and expected labels live in `evals/datasets/`. No real contract or client data is published. Local private data can use ignored `data/private/`, but ignore rules do not replace a staged-file review.
