# Design profile

14 October 2026 · Companion to [UI Master](UI%20Master.md), preserving the approved visual direction.

## Intended experience

A recognizable 3D process hub helps the reviewer understand the workflow. Clicking a station leads to a practical source/decision interface. The core legal-review destination gives evidence more space than decoration; the hub uses object silhouettes to distinguish sections.

## Visual inputs and decisions

UI 2 establishes the round shell, concave toolbar notch, two-part icon rail and integrated panel language. UI 3 establishes retro thick-bevel workstation geometry, polished colored resin, chunky keys, cream cable and soft product lighting. UI 1 demonstrates integration, but its layout/branding/assets are not copied.

The owner clarified Anduin Blue/Mint as the primary palette and requested a clean composition easy to separate into Blender modules. The selected hub has two ordered workflow lanes, one dominant review workstation and subordinate section objects. Decorative room architecture, excess connector tubes, glow and extra props were removed in the approved refinement.

## Light and dark

Original light assets remain unchanged. Dark companions theme UI chrome/surfaces/text and studio ambient light, retaining paper-light document pages, recognizable object material colors, exact functional states and controls. Theme does not change a contract, add a field or unblock an action. The palette and each screen's mapping are detailed in UI Master.

## Review and iteration

The owner first approved the blue modular hub, then requested individual interfaces/objects and dark companions. Source/version/option/stepper corrections were recorded as targeted refinements. Future changes should preserve unrelated approved regions and record validation honestly.

These are static design concepts. Runtime interactions, responsiveness, 3D topology/animation and model/legal-review quality require separate implementation and evidence. This profile documents design decisions for judges; it is not a claim of an official Anduin product or completed application.
