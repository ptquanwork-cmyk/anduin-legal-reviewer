All use the common blue/mint resin, white polymer, soft upper-left light and elevated three-quarter camera. No titles, numbered plaques, surrounding hub stage or unrelated modules belong in a component image. Alpha/dimensions and source-image identity are recorded in [validation](../manifests/validation.json) after verification.

Actual delivered size: **1254 × 1254 pixels, RGBA** for each component. Fully transparent pixels and four transparent corners are present; the substantial silhouette (alpha ≥128) stays inside the frame. No upscaling or raster post-editing was applied. These remain modeling references rather than reconstructed geometry.

See [Blender handoff](../blender/README.md) for scene organization and proposed motion. An image reference cannot determine hidden topology, dimensions or rigging, and does not guarantee automatic reconstruction by a Blender add-on. The approved homepage remains byte-identical; these are newly generated supporting references.
