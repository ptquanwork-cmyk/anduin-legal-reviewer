# Functional interface concepts

These are nine **static synthetic design examples**, one destination for each homepage station. They share the approved homepage's shell, rail, blue/mint palette and a small 3D section identity. Functional source text and controls sit on readable opaque surfaces.

| ID | Screen | Intended layout and behavior |
| --- | --- | --- |
| 01 | [Intake](01-intake.png) | Upload, source/version metadata, resumable jobs and duplicate candidates |
| 02 | [Source quality](02-source-quality.png) | Word/PDF comparison and source-quality issues; unresolved gates remain visible |
| 03 | [Document map](03-document-map.png) | Outline, relationship/page-map views and source-linked node detail |
| 04 | [Legal review](04-legal-review.png) | Source PDF, exact competing passages, finding explanation and human decisions |
| 05 | [Decision/report](05-decision-report.png) | Decision history, revision status, questions/report and handoff gates |
| 06 | [Annotation](06-annotation.png) | Source regions, exactly four types, properties/groups and transfer uncertainty |
| 07 | [Form preview](07-form-preview.png) | Full original content, controls, source comparison and missing coverage |
| 08 | [Responses](08-responses.png) | Version-linked answers, draft/review actions and missing required items |
| 09 | [PDF QA/export](09-pdf-qa-export.png) | Draft preview, mapping/value/render checks and blocked final export until verified |

States shown across screens illustrate different points in the proposed process, not one completed real run. A source-quality failure, unresolved legal issue, unmapped block, missing answer or clipping issue can deliberately block a next action. Confirmed/open and resolved after revision are different states.

The exact generation prompts and plan-step mapping are in [the prompt matrix](../prompts/interfaces-components-v1.json). These are design references, not a built website. Generative small text is subject to review; the specification and exact prompt copy define intended behavior.

Actual delivered size: **1536 × 1024 pixels** for each screen. [Refinement records](../prompts/generation-refinements-v1.json) capture navigation, source page count and form-option corrections. All numbers/job states are illustrative; the viewer's 100% label is zoom rather than extraction accuracy.
