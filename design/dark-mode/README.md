# Dark-mode companion images

Ten theme-only companions: the approved 3D homepage and nine functional interfaces. Original light images, transparent object references, reference JSONs and the previous ZIP remain unchanged.

Use dark navy/charcoal chrome, near-white text and the same Anduin Blue/Mint accents. Source-document pages/thumbnails stay light with original dark ink; 3D blue/mint and white/cream object bodies retain their identity. Positions, controls, data and states follow each corresponding light image.
