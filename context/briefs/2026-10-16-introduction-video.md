# Introduction video

Date: 16 October 2026.

Request: an introduction video of the web app with clear animations, click sounds, zoom in and out, and music. The owner asked for a "Claude Motions" tool. No tool by that name exists in the session or the plugin catalogue. The owner then installed the Remotion plugin and asked to use it.

| Topic | Decision |
| --- | --- |
| Tool | Remotion (the plugin's skills only load in a new session, so the Remotion library is used directly) |
| Music | Original, synthesised in code (owner's choice); no third-party audio |
| Length | 60–90 seconds (68.5 s delivered) |
| Captions | English, one per step |
| Content | Real screens of the app with the synthetic demo agreement only; no AI-vendor names |
| Files | Sources, screenshots and a 30 MB web copy in `demo/video/`; the 73 MB master and generated audio stay local and can be rebuilt |

## Revision: calm, sectioned, results first

The owner asked that the screen stop pulsing with the beat, that the layout be clearer section by section with transitions between sections, that captions and flow be short, and that the numbers from the scenario test report open the video, followed by the usage process. Animations and graphics should be present but restrained.

Delivered: 89 s; results and speed cards first (including the known limit), then six chapters with title cards; no beat pulse; one caption per shot. The 28 MB web copy replaces the previous one.
