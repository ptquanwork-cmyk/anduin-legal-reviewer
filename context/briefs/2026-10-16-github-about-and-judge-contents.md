# GitHub About section and judge contents

Date: 16 October 2026.

Request: add an About section on GitHub, not in the web app. The application interface stays unchanged. The section covers:
- the owner, with portfolio, LinkedIn and a CV summary;
- the project as the owner's take on the hackathon and its topic;
- a table of contents that makes the repository easy to navigate: purpose, structure, languages and tests.

The audience is a company judge assessing the hackathon.

| Topic | Decision |
| --- | --- |
| Placement | Repository README and the GitHub repository description/topics; no change to the web app |
| Source | The owner's Master CV and portfolio content bank (9 October 2026) |
| Public contact details | Portfolio, LinkedIn and GitHub only. No email or phone number, and no references' contact details |
| CV form | Short summary on the page; full CV through the portfolio |
| Judge path | Contents table, a two-minute walkthrough, technology and languages, testing and evidence with recorded results, security, status and limitations, and a reading order |
