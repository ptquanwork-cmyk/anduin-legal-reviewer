# Build log — 15 October 2026

Scope: build the working single-page application from the three primary specifications ([brief](../../context/briefs/2026-10-15-runtime-application-build.md)). Results below are what was actually run and observed; limitations are listed at the end.

## Built

- **Application** (Next.js 16 App Router, React 19, Tailwind 4, Motion, three.js/react-three-fiber, pdf.js, pdf-lib): 3D hub plus nine workspaces, Templates and Feedback in one page; URL keeps the screen and version (`?s=review&v=…`). Design frame of 1536 × 1024 scaled to the viewport on desktop; flow layout below 900 px wide.
- **Supabase**: three migrations (schema + RLS + storage + Realtime; annotation agent/help columns; worker endpoint registry).
- **Review pipeline**: PDF extraction with page geometry and real font names (pdf.js with `fontExtraProperties`), Word inspection (mammoth + `word/*.xml`), conversion comparison, rules, semantic adapter, evidence validator, decision-agent routing/ordering, field detection with content-based transfer.
- **Digitisation**: annotation editor and QA, full-content form model, responses with autosave, PDF fill with clipping detection and four read-back QA checks, review report PDF.
- **Worker**: FastAPI service with Laya (`predict` and batched `predict_batch`) and Word conversion (Word COM on Windows, LibreOffice in Docker); Supabase-session authentication; local runner with Cloudflare quick tunnel, URL publication and watchdog.
- **Blender**: nine stations built by script, exported to GLB, rendered live in the hub with hover cues and the station-to-header flight.

## Security review follow-up

An automated review flagged two issues; both were fixed and re-verified on production:

1. *Worker endpoint registry*: an anonymous caller could have claimed an unclaimed endpoint and redirected worker traffic. The endpoint had already been claimed by the owner's run; the claim function was dropped, `set_worker_url` now requires the seeded hash and a `*.trycloudflare.com` host, and the app checks the same host pattern before sending a session token.
2. *Word automation on untrusted files*: macro-enabled packages are rejected, external relationships other than hyperlinks are stripped, and Word runs with macros forced off and no prompts. `worker/test_sanitize.py` passes. A production upload afterwards converted in 13.6 s and produced the expected findings.
